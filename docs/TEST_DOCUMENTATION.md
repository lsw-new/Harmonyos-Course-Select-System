## 5. 并发与高风险规则专项

| 风险点 | 测试手段 | 结论 |
|---|---|---|
| 选课超容量（先 COUNT 再 INSERT 竞态） | 20 并发抢 1/5 名额 ×2 + 去锁对照 | `FOR UPDATE` 行锁下落库数恒 ≤ 容量；去锁复现超卖证明断言有效 |
| 实践报名超名额 | 同上行锁压测 | 同上 |
| 轮次状态竞态覆写 | 条件更新（WHERE 带期望状态）+ 409 测试 | 终态不可被并发覆写 |
| 水平越权（IDOR） | 伪造 studentId 参数请求 | 后端一律以 JWT 学号为准，伪造无效 |
| 注入 | 数据库管理表/列白名单 + 参数化测试 | 非法表/列被拒或丢弃 |
| 信息泄露 | 500 响应内容断言 | 仅通用文案，不含连接串/凭据/堆栈 |
